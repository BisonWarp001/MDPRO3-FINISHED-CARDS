Cartas Custom para MDPRO3 por BisonWarp001.

Algunas cartas fueron recopiladas de foros o videos de internet y programadas para MDPRO3, con la única finalidad de divertir.

Se han tomado cartas de este foro https://www.reddit.com/r/customyugioh/comments/16gxj76/egyptian_god_support/?tl=es-419, puede que algunas se hayan modificado para adaptarlos a mi gusto.

Todos los derechos reservados para BatMed. Ví un video en youtube https://www.youtube.com/watch?v=kpUpH0AWsgE&t=1167s que creó BatMed. Recreé las cartas para jugar en MDPRO3, Todo está basado en sus cartas.

De aquí tomé ideas para dichas cartas https://www.youtube.com/watch?v=t45khDWMS4k&t=1s

Algunos cambios se encontrarán debido a problemas de programación pero la mayoria son los mismos. Sin fines de lucro.

Dentro de MDPRO3. 
  1 Copiar y pegar la carpeta Expansions, de ser necesario solo reemplacen, o copien y peguen las carpetas dentro de esta.
  2 La carpeta Art2 contiene el arte de las cartas. Copiar y pegar la carpeta "Art2" dentro de "Picture".
  3 Copiar los archivos dentro de la carpeta "Deck" en la carpeta del mismo nombre del juego.
